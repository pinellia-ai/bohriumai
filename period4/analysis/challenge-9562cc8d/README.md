# publication-figure-builder — 科研数据可视化

> 波尔产品周赛第4期 · analysis 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「科研数据可视化」的可调用 Skill（publication-figure-builder）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装后由官方 DeepSeek Harness 在 3 个固定案例运行（64 请求/900秒/16384token），与基础 Agent 对照评分。本包不含预制答案。

## 2. 快速调用

- 触发："请按本 Skill 从数据表生成可投稿图件（口径声明+可复现）"
- 输入：`/input/case.json`（含 case_id、任务、数据字典/材料、output_contract）+ 数据文件。
- 输出：`/app/output/`（数据/图/代码 + result.json，字段以 output_contract 为最高优先）。

## 3. 方法概述

-  统计假设是否成立（比较类需检验类型匹配）。
-  图表类型按数据关系选：`{比较→柱/箱线, 关系→散点, 趋势→折线, 构成→堆叠（慎用饼图）, 分布→直方/小提琴}`，选择理由登记。
-  位置/长度编码不截断（截断轴必须显式标注）；色阶线性一致；颜色数=分类数；色觉安全（冗余编码：形状/纹理/标签）。
-  误差线含义注明（SD/SEM/CI 按数据）；样本量标注。
-  轴标签+单位+量级、图例、显著性标记（与检验对应）、面板编号（a,b,c）、图注覆盖读图所需全部信息。
-  按目标要求导出（分辨率/矢量/字体嵌入）；绘图代码交付（数据→图可一键重绘）；图-数据对应关系登记（哪列→哪个编码）。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；保留原始值/规则/结果/代码与质量检查。
- 缺失、异常、无法解释如实说明；partial 时已完成部分完整可交；不编造。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 数据/材料缺失 | status=failed 写明 |
| 无法解释的结果 | uncertainty 如实登记 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
