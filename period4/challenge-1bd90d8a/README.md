# data-figure-editor — 科研数据图表生成与编辑

> 波尔产品周赛第4期 · graphics 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「科研数据图表生成与编辑」的可调用 Skill（data-figure-editor）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装后由官方 DeepSeek Harness 在 3 个固定案例运行（64 请求/900秒/16384token），与基础 Agent 对照评分。本包不含预制答案。

## 2. 快速调用

- 触发："请按本 Skill 生成/编辑数据图表：图元校验+可编辑源文件"
- 输入：`/input/case.json`（含 case_id、任务、数据字典/材料、output_contract）+ 数据文件。
- 输出：`/app/output/`（数据/图/代码 + result.json，字段以 output_contract 为最高优先）。

## 3. 方法概述

-  映射表：`{数据列 → 图元(柱高/点位/色阶/角度/误差线)}`，逐项校验：柱高=数值×比例（截断轴时显式标注）。
-  数值抽查：随机抽 3 个图元反向读值 vs 数据，误差≤1%。
-  轴标签+单位+量级、图例完整、误差线含义（SD/SEM/CI 按数据来源）、显著性标记与检验对应、样本量——缺一补一。
-  字号/线宽/配色/面板布局/留白按目标模板；配色=分类数、色觉安全；导出参数合规。
-  交付：源文件（脚本或矢量 SVG，数据驱动的重绘）+ 导出件（PNG/PDF）；编辑接口说明（改哪个文件哪个参数改什么）。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；保留原始值/规则/结果/代码与质量检查。
- 缺失、异常、无法解释如实说明；partial 时已完成部分完整可交；不编造。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 数据/材料缺失 | status=failed 写明 |
| 无法解释的结果 | uncertainty 如实登记 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
