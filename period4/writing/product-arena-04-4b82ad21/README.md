# intro-related-work-writer — 写作08｜引言与相关工作写作

> 波尔产品周赛第4期 · writing 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「写作08｜引言与相关工作写作」的可调用 Skill（intro-related-work-writer）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装后由官方 DeepSeek Harness 在 3 个固定案例运行（64 请求/900秒/16384token），与基础 Agent 对照评分。本包不含预制答案。

## 2. 快速调用

- 触发："请按本 Skill 写引言与相关工作：脉络、分组比较、空白论证"
- 输入：`/input/case.json`（含 case_id、任务、事实底稿、output_contract）+ 材料文件。
- 输出：`/app/output/`（稿件文件 + result.json，字段以 output_contract 为最高优先）。

## 3. 方法概述

-  拒绝空转铺垫：每句背景绑定具体文献/事实，形成"已知→局限→问题"递进链。
-  背景深度服务后文：铺垫到"读者能理解本文要解决什么"即止。
-  按问题/方法/技术路线**分组比较**（不是逐篇摘要拼接）：每组内文献按方法异同对比。
-  每篇转述三要素：结论 + 适用条件 + 局限——准确转述，不改写结论强度。
-  研究空白 = 从已引文献的局限**推导**：`文献A止步于X（引）→ 文献B未覆盖Y（引）→ 因此 Z 未被解决（本文切入）`。
-  空白句每一步可回查文献；无文献支撑的空白不写。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；事实/数字/引用保留来源或修改记录。
- 材料不足与冲突显式标注；partial 时已完成部分完整可交；不编造。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 底稿缺失/损坏 | status=failed 写明 |
| 约束冲突 | 以实际材料为准 + 登记 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
