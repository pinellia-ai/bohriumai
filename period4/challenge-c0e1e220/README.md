# stats-analysis-interpreter — 统计分析与结果解读

> 波尔产品周赛第4期 · analysis 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「统计分析与结果解读」的可调用 Skill（stats-analysis-interpreter）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装后由官方 DeepSeek Harness 在 3 个固定案例运行（64 请求/900秒/16384token），与基础 Agent 对照评分。本包不含预制答案。

## 2. 快速调用

- 触发："请按本 Skill 做统计分析并给三层解读（有无/多大/多确定）"
- 输入：`/input/case.json`（含 case_id、任务、数据字典/材料、output_contract）+ 数据文件。
- 输出：`/app/output/`（数据/图/代码 + result.json，字段以 output_contract 为最高优先）。

## 3. 方法概述

-  正态性（检验+图）、方差齐性、独立性、配对结构——检查结果留档，**不满足时选替代检验并说明**。
-  检验选择依据表：`{比较, 数据类型, 用的检验, 为什么}`；检验名+统计量+自由度+精确 p 报告。
-  多重比较：校正方法与校正后 p 同报。
-  效应量（差值/比值/η² 等）+95%CI——**只有 p 不够**：显著但效应小要明说。
-  图：带误差线/区间可视化（含义注明 SD/SEM/CI）。
-  三问作答：有没有（统计显著+方向）、有多大（效应量实际含义）、多确定（CI 宽度/样本限制）。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；保留原始值/规则/结果/代码与质量检查。
- 缺失、异常、无法解释如实说明；partial 时已完成部分完整可交；不编造。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 数据/材料缺失 | status=failed 写明 |
| 无法解释的结果 | uncertainty 如实登记 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
