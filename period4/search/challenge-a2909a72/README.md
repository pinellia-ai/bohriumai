# multi-round-literature-search — 学术文献检索

> 波尔产品周赛第4期 · search 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「学术文献检索」的可调用 Skill（multi-round-literature-search）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装至评测环境 skill 目录后，官方 DeepSeek Harness 在 3 个固定案例上运行（64 请求/900秒/16384token），与基础 Agent 对照评分。离线语料口径：仅依据组织方快照，不声称实时检索与全球覆盖。

## 2. 快速调用

- 触发："请按本 Skill 对给定研究问题做多轮文献检索并保留依据"
- 输入：`/input/case.json`（含 case_id、任务、语料清单、output_contract）+ 语料文件。
- 输出：`/app/output/result.json`（字段以 case.json output_contract 为最高优先）。

## 3. 方法概述

-  研究问题 → 子问题清单（对象/机制/方法/时间范围/证据要求），每个子问题独立可检索。
-  每个子问题生成查询式：核心词 + 同义词 + 缩写 + 变体；规划检索顺序（先核心后外围）。
-  在语料上逐查询匹配：标题/摘要/关键词字段优先，作者与年份作辅助过滤。
-  每轮记录：`{查询式, 匹配字段, 命中数, 命中记录ID}`——检索过程可复跑。
-  轮末评估：子问题覆盖情况、新命中占比。**新增命中趋零且子问题全部覆盖 → 停止**（停止条件显式写出）。
-  补检策略：换字段、扩术语、放松时间窗——每轮补检必须带来新增命中，空转轮如实标注。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；每条结果带来源定位与原文短句。
- gaps/uncertainty_notes 诚实登记；status=partial 时已完成部分完整可交。
- 不编造记录/引用/状态/覆盖。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 语料缺失/损坏 | status=failed |
| 子任务零命中/无数据 | 如实登记 + 已试策略列表 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
