# patent-tech-search — 专利与技术文献检索

> 波尔产品周赛第4期 · search 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「专利与技术文献检索」的可调用 Skill（patent-tech-search）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装至评测环境 skill 目录后，官方 DeepSeek Harness 在 3 个固定案例上运行（64 请求/900秒/16384token），与基础 Agent 对照评分。离线语料口径：仅依据组织方快照，不声称实时检索与全球覆盖。

## 2. 快速调用

- 触发："请按本 Skill 完成专利五问检索：保护/同族/有效性/同主题/权限"
- 输入：`/input/case.json`（含 case_id、任务、语料清单、output_contract）+ 语料文件。
- 输出：`/app/output/result.json`（字段以 case.json output_contract 为最高优先）。

## 3. 方法概述

-  从检索需求提取技术要素（结构/方法/用途），形成主题要素表——查新比对的基准。
-  **Q1 保护什么**：解读独立权利要求（材料内文本）→ 保护范围要点（技术特征分解），引用原文条号。
-  **Q2 同族关系**：按族标识/优先权号归并成员，输出族谱（成员/国家/日期），依据=快照字段。
-  **Q3 有效性**：只用快照内的法律状态字段，标注"截至快照日期"；材料无此字段 → 如实登记，不编造。
-  **Q4 同主题玩家**：技术要素在快照内匹配其他专利与文献——每条给要素重合依据。
-  **Q5 权限**：逐源登记许可状态；不明标 unknown。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；每条结果带来源定位与原文短句。
- gaps/uncertainty_notes 诚实登记；status=partial 时已完成部分完整可交。
- 不编造记录/引用/状态/覆盖。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 语料缺失/损坏 | status=failed |
| 子任务零命中/无数据 | 如实登记 + 已试策略列表 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
