# code-gen-executor — 科研代码生成与执行

> 波尔产品周赛第4期 · analysis 赛道 · Skill 交付包使用与方法说明

## 1. 这是什么

围绕「科研代码生成与执行」的可调用 Skill（code-gen-executor）：组织方为本题准备 3 个固定案例。每个案例包含任务说明、科研材料、必要的输入约束和评分所需的证据范围；案例会以相同内容分别交给基础 Agent 和加载参赛 Skill 的 Agent。你不需要自带正式测试案例，也不需要提交预先写好的答案。…

评测方式：安装后由官方 DeepSeek Harness 在 3 个固定案例运行（64 请求/900秒/16384token），与基础 Agent 对照评分。本包不含预制答案。

## 2. 快速调用

- 触发："请按本 Skill 生成并真实执行数据分析代码，报错根因修复"
- 输入：`/input/case.json`（含 case_id、任务、数据字典/材料、output_contract）+ 数据文件。
- 输出：`/app/output/`（数据/图/代码 + result.json，字段以 output_contract 为最高优先）。

## 3. 方法概述

-  依赖清单（包+版本）登记；环境不可用项如实（不冒充已装）。
-  清洗代码：处理列名统一、缺失、重复、单位（规则编号注释在代码内）。
-  分析代码：统计/绘图按任务要求；**硬编码路径为零**（相对路径+参数化）。
-  真实执行：报错逐条定位根因（行号+原因）修复再跑；输出与手工抽查核对（抽 3 行/值验证脚本正确性）。
-  运行日志保留：`{命令, 退出码, 输出摘要}`——结果可追溯到真实运行。
-  代码（注释完整、可复跑：README 写明依赖/入口/顺序）+ 输出文件 + 核对记录。

## 4. 契约速览

- case_id 原样；status ∈ success|partial|failed；保留原始值/规则/结果/代码与质量检查。
- 缺失、异常、无法解释如实说明；partial 时已完成部分完整可交；不编造。

## 5. 异常速查

| 情况 | 处置 |
|---|---|
| 数据/材料缺失 | status=failed 写明 |
| 无法解释的结果 | uncertainty 如实登记 |
| 预算不足 | 落盘 partial，gaps 列剩余 |
| contract 与本文件冲突 | 以 case.json output_contract 为准 |
